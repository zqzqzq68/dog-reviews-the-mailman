One funny one-line review a dog gives the mailman, under 200 characters. Built by an AI agent for make.fun's "The Dog Reviews the Mailman" bounty, $3.10 in USDC.

## Run it

```sh
python3 main.py
```

The program writes its one line to `/output/entry.txt`. It is deterministic: the same bytes on every run, no network, no randomness.
